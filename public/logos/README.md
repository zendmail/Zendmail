# Store brand logos

Place the official logo files here (they are used on Settings → Commerce → Stores):

- `shopify.svg` — from the Shopify brand assets page (shopify.com/brand-assets)
- `woocommerce.svg` — from the WooCommerce brand/press assets (woocommerce.com/brand-and-logo-guidelines)

Use the official files unmodified and follow each platform's logo usage guidelines.
Until a file is present, the UI falls back to a generic icon.
